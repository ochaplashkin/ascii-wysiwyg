= Демо сравнения AsciiDoc
:description: Изменённая версия документа для сравнения

== Введение

Этот документ показывает, как настоящий HTML-рендер и сравнение работают вместе.
Слева находится оригинал, справа — обновлённая версия с несколькими правками.

NOTE: Изменённые блоки подсвечиваются красным и зелёным цветом.

== Что умеет редактор

* Rich-text редактирование через Quill
* Генерация AsciiDoc из HTML
* Настоящий HTML-рендер через Asciidoctor
* Подсветка синтаксиса в предпросмотре
* Таблицы, списки и цитаты

== Итог

Сравнение отрендеренных документов помогает заметить смысловые изменения,
не отвлекаясь на исходную разметку.

Теперь различия видны сразу: изменённые блоки выделены цветом,
а неизменённые блоки остаются на своих местах.
