= Демо сравнения AsciiDoc
:description: Оригинальная версия документа для сравнения

== Введение

Этот документ показывает, как настоящий HTML-рендер и сравнение работают вместе.
Слева находится оригинал, справа — изменённая версия.

TIP: Изменённые блоки подсвечиваются красным и зелёным цветом.

== Что умеет редактор

* Rich-text редактирование через Quill
* Генерация AsciiDoc из HTML
* Подсветка синтаксиса в предпросмотре
* Таблицы, списки и цитаты

== Таблица параметров

[cols="2,1,3",options="header"]
|===
|Параметр |Значение |Описание

|`theme` |`github` |Тема подсветки синтаксиса
|`language` |`ru-RU` |Язык интерфейса
|`editor` |`quill` |Движок редактора
|===

== Пример кода

[source,javascript]
----
const diff = compare(oldDocument, newDocument);
console.log(diff.changes.length);
----

== Зачем это нужно

Сравнение блоков позволяет быстро увидеть, что изменилось в документе.

== Итог

Сравнение отрендеренных документов помогает заметить смысловые изменения,
не отвлекаясь на исходную разметку.
